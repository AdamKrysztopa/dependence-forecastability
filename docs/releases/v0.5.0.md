# v0.5.0 — Review-driven hardening: math honesty, architecture realignment, efficiency reset

See the full migration guide at
[`docs/migration/v0.4.x_to_v0.5.0.md`](../migration/v0.4.x_to_v0.5.0.md).

## Breaking changes

- **Default AMI estimator changed from KSG-I to KSG-II.**  `compute_ami`,
  `compute_pami_linear_residual`, `compute_ami_information_geometry`, and all
  surrogate-band scorers now use the unified Chebyshev `KSG2CurveKernel` by
  default.  Results will differ from v0.4.3 by a few percent on typical
  inputs.  Pass `estimator='ksg1_sklearn'` to reproduce v0.4.3 numerics
  exactly.

- **`compute_transfer_entropy` removed.**  Importing it now raises
  `ImportError`.  Replacements: `compute_transfer_entropy_ksg` (true Schreiber
  TE via Frenzel-Pompe KSG-CMI) and `compute_predictive_information_gain`
  (legacy residual-MI under an honest name).

- **Significance correction defaults to Romano-Wolf FWER.**  The surrogate
  band now applies step-down family-wise correction across lags by default
  (`correction='romano_wolf'`).  Pass `correction='none'` to reproduce v0.4.3
  per-lag uncorrected behaviour.

- **`n_surrogates` default raised from 99 to 999.**  Code relying on the old
  default runtime cost must now pass `n_surrogates=99` explicitly.  The
  `ge=99` validation floor is unchanged.

- **`signal_to_noise` renamed to `informative_mass_fraction`.**  Affected
  types: `AmiInformationGeometry`, `ForecastabilityFingerprint`.  The caution
  flag value `"low_signal_to_noise"` is now `"low_informative_mass_fraction"`.
  Accessing the old attribute name raises `AttributeError` with a migration
  message.

- **`adapters/pydantic_ai_agent.py` shim removed.**  Importing from the old
  shim path raises `ImportError`.  Agent adapter paths have moved to
  `adapters/agents/{payloads,runtime}/`.

- **Dead DTOs removed.**  `use_cases/requests.py` and `use_cases/responses.py`
  are deleted.  `extensions.py` and `exog_benchmark.py` are moved into
  `use_cases/`.

- **Domain module import paths changed.**  18 modules are now under
  `src/forecastability/domain/`.  Deep internal imports will break.  Use the
  stable `forecastability` facade; see migration guide section 4.

## Added

- `compute_transfer_entropy_ksg` — true Schreiber transfer entropy via the
  Frenzel-Pompe KSG-CMI estimator
  (`src/forecastability/diagnostics/cmi_ksg.py`).
- `compute_predictive_information_gain` — honest rename of the legacy
  residual-MI estimator.
- `SignificanceCorrectionService` — Romano-Wolf step-down,
  Benjamini-Hochberg, and Benjamini-Yekutieli corrections across lags
  (`src/forecastability/services/significance_correction_service.py`).
- `RoutingConfidenceCalibrationAudit` frozen Pydantic model; calibration
  thresholds now derived from a stated precision target
  (`docs/calibration/v0_5_0_routing_confidence.md`).
- Physical `src/forecastability/domain/` package replaces the
  allowlist-virtual layer; architecture boundary tests now use structural
  directory walks.
- `forecastability.api` — curated ~25-name public surface;
  `forecastability._legacy` emits `DeprecationWarning` for notebook-compat
  names.

## Performance

- Vectorized hot loops: phase-randomization batching (single batched FFT call
  for all surrogates), ordinal pattern indexing, Theiler-window filter, DFA
  fluctuation (RVH-F04).
- Incremental QR partial-curve residualization replaces the previous
  loop-per-lag approach (RVH-F05).
- Request-scoped memoization in `run_triage` for `_scale_series`, Welch PSD,
  and AMI curve (RVH-F06).
- PBE-F28/29/30 performance budget tests added; budgets stored in
  `tests/perf_budgets.yml`.

## Architecture

- Physical `src/forecastability/domain/{models,value_objects,scoring_protocols}/`
  package created; 18 modules migrated from allowlist-virtual paths.
- `triage/comparison_report.py` split into domain model
  (`domain/models/comparison_report.py`) and renderer
  (`reporting/comparison_report_plots.py`).
- `adapters/agents/` and `adapters/llm/` merged into
  `adapters/agents/{payloads,runtime}/`.
- All PydanticAI tool return types converted to frozen Pydantic models
  (no `dict[str, Any]` on public boundaries).

## Fixed

- Fixed Frenzel-Pompe cutoff calculation in
  `compute_conditional_mutual_information_ksg` (Chebyshev radius was computed
  on the wrong axis; commit 6bdd532).
- Welch `nperseg` clamped to series length to prevent zero-division on short
  series (RVH-F07).
- Lyapunov exponent estimation switched to linear-window fit, eliminating
  noise sensitivity in the nonlinear oscillator branch (RVH-F07).
- `compute_pami_linear_residual` now emits `UserWarning` on low-cardinality
  inputs instead of silently computing on inappropriate data (RVH-F21).

## Internal

- Numerical golden tests: Gaussian-MI round-trip and KSG-II vs KSG-I
  regression-fixture diff (`tests/test_gaussian_mi_golden.py`,
  `tests/test_v0_5_0_regression_fixtures.py`).
- `n_surrogates >= 99` floor asserted inside
  `KSG2CurveKernel.estimate_surrogate_band`.
- Surrogate self-exclusion slot-0 assertion added in `KSG2CurveKernel`
  (RVH-F19).
- CMI sample-size rule updated to `N >= k^(d+2)` (RVH-F20).
- All public docstrings audited: pAMI linear-approximation disclosure,
  geometry-threshold heuristic disclosure, overstatement cleanup (RVH-F22).
